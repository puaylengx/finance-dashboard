3Setup & Run

Prerequisites

  • Python 3.12+
  • PostgreSQL 14+ (local หรือ remote via SSH)
  • Redis 7+ (optional — ถ้าไม่มีจะ disable cache อัตโนมัติ)

ติดตั้งและเริ่มใช้งาน

# 1. สร้าง virtual environment
cd backend
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

# 2. ติดตั้ง dependencies
pip install -r requirements.txt

# 3. ตั้งค่า environment
cp .env.example .env
# แก้ไข .env ด้วย DB credentials ของคุณ

# 4. Run migrations
python migrations/migrate.py

# 5. Start server
uvicorn app.main:app --reload --port 8000
✓ พร้อมใช้งาน เปิด http://localhost:8000/api/docs เพื่อดู Swagger UI
หรือ http://localhost:8000/api/redoc สำหรับ ReDoc

Connection Pool

# app/core/database.py
_pool = AsyncConnectionPool(
    conninfo=conninfo,
    min_size=2,      # DB_POOL_MIN_SIZE
    max_size=20,     # DB_POOL_MAX_SIZE
    kwargs={"cursor_factory": AsyncClientCursor},
    # AsyncClientCursor ใช้ %(name)s syntax แบบ psycopg2
)

# Usage
async with get_db() as conn:
    async with conn.cursor() as cur:
        await cur.execute(sql, params)
ℹ AsyncClientCursor psycopg3 ใช้ AsyncClientCursor เพื่อให้ syntax %(name)s เหมือน psycopg2 ทุกประการ โดยเฉพาะ pattern %(param)s IS NULL ที่ใช้ใน finance queries

6Redis Cache

Cache ลด DB load สำหรับ query หนักๆ — ถ้า Redis ไม่พร้อม ระบบทำงานต่อได้โดยอัตโนมัติ (cache disabled gracefully)

Key PatternTTLเก็บอะไร
seamless:v1:budget:{role}:{hash}300s (5 min)Budget dashboard payload
seamless:v1:io:{role}:{hash}300s (5 min)IO dashboard payload
seamless:coordinator:{lower(username)}600s (10 min)Coordinator lookup result (1/0) — key เป็น lowercase ของ username หรือ UPN
# Cache invalidation หลัง add/toggle coordinator
# ลบทั้ง UPN key และ username key เพื่อ dual-lookup ถูกต้อง
if upn:
    await invalidate_coordinator_cache(upn)     # key: lower(upn)
await invalidate_coordinator_cache(username) # key: lower(username)

Audience Validation

ตรวจสอบ aud claim แบบ manual เพื่อรองรับทั้ง 2 format:

# app/services/auth_service.py
valid_audiences = {settings.azure_client_id, f"api://{settings.azure_client_id}"}
if claims.get("aud") not in valid_audiences:
    return None   # reject invalid audience

Graph API Fallback (jobTitle)

บาง Entra token อาจไม่มี jobTitle claim — ถ้าตั้ง AZURE_CLIENT_SECRET ระบบจะ fallback ดึงจาก Microsoft Graph API:

# ดึง app token ด้วย client_credentials flow (cached)
await _fetch_graph_app_token()
# เรียก GET https://graph.microsoft.com/v1.0/users/{oid}?$select=jobTitle
await _get_job_title_from_graph(oid)
ℹ Graph Token Cache App token จาก client_credentials ถูก cache ใน memory (_graph_token_cache) จนหมดอายุ (ปกติ 3600s) — ไม่ดึงใหม่ทุก request
